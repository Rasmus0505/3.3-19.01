# 阅读板块词汇简化功能 - 产品需求文档

## 1. 背景与目标

### 问题陈述
当前阅读板块的词汇简化功能存在以下问题：
- 词典筛选不够精准，可能将简单词误标为高难度词
- 所有超纲词都被重写，无法区分"值得学习的词(i+1)"和"过于难的词(>i+1)"
- 用户看不到原文视图和重写视图之间的明确区别

### 产品目标
为语言学习者提供智能化的阅读辅助：
1. 保留值得学习的词汇（i+1），用绿色下划线标注，鼓励主动学习
2. 将过于困难的词汇（>i+1）智能替换为 i+1 水平，保持学习挑战性但不过于挫败
3. 过滤词典误标的简单词汇，减少不必要的干扰
4. 提供清晰的视觉反馈，让用户一眼区分"可学习词"、"需简化词"、"已简化词"

## 2. 核心流程

### 三步处理流程

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: 本地词典初筛                                             │
│  ─────────────────                                             │
│  • 用户粘贴英文文章                                               │
│  • VocabAnalyzer 根据词典自动识别 i+1 和 >i+1 的词汇              │
│  • 输出候选词列表 + 词典标注等级                                   │
└───────────────────────────┬─────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: DeepSeek 二次筛选 + 重写                                  │
│  ─────────────────────────────────────────────────────────────   │
│  • 验证每个候选词是否真的需要作为学习目标                            │
│  • 过滤过于简单的词（词典误标或用户已掌握）                         │
│  • 将 >i+1 词重写为 i+1 水平的词/短语（可以是2-3词的短语）         │
│  • 返回：有效i+1列表、有效>i+1列表、被过滤词、重写映射               │
└───────────────────────────┬─────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: 双视图渲染                                               │
│  ──────────────────                                              │
│  原文视图：                                                       │
│    • i+1 词 → 绿色下划线（可学习）                                │
│    • >i+1 词 → 红色下划线（建议简化）                              │
│    • 已简化词 → 黄色背景块 + 悬浮显示原文                           │
│                                                                  │
│  重写版视图：                                                      │
│    • >i+1 词已被替换为 i+1 水平的词/短语                           │
│    • 所有简化词用黄色背景块 + 悬浮显示原文对照                       │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 用户故事

### 用户故事 1: 保留学习机会
**作为** 英语学习者
**我想要** 在阅读时看到哪些是"跳一跳够得着"的词汇（i+1）
**以便** 我可以有针对性地学习这些有价值的生词

### 用户故事 2: 智能简化
**作为** 英语学习者
**我想要** 系统自动把太难的词（>i+1）换成我能理解的表达
**以便** 我能流畅阅读文章，而不会因为个别难词卡住

### 用户故事 3: 过滤误标
**作为** 英语学习者
**我想要** 系统过滤掉词典误标的简单词
**以便** 我不会被无关的词汇干扰

### 用户故事 4: 追溯原文
**作为** 英语学习者
**我想要** 看到简化后的词时能对照原文
**以便** 我理解替换前后的差异，学习地道的表达

## 4. 功能详细说明

### 4.1 DeepSeek 二次筛选

**输入：**
- 原文全文
- 词典筛选出的候选词列表（含词典标注等级）
- 用户当前等级 (i)
- 目标等级 (i+1)

**输出：**
```json
{
  "valid_i1_words": ["peruse", "scrutinize"],           // 有效的 i+1 词
  "valid_above_i1_words": ["eschew", "ubiquitous"],    // 有效的 >i+1 词
  "removed_words": [
    {"word": "fixing", "reason": "词典误标，实际为A2水平"}
  ],
  "simplified_words": ["avoid", "found everywhere"],     // 重写（与 above_i1 一一对应）
  "word_levels": {
    "peruse": "B2", "scrutinize": "B2", "eschew": "C1", "ubiquitous": "C2"
  }
}
```

**筛选规则：**
1. **i+1 判断**：词汇等级等于目标等级 → 保留为学习词汇
2. **>i+1 判断**：词汇等级高于目标等级 → 需要简化
3. **过滤判断**：词典标注与实际不符（如 A2 词被标为 B2）→ 移除
4. **重写规则**：必须是 i+1 水平的词/短语，可以是 2-3 词的短语

### 4.2 原文视图渲染

| 词的类型 | 视觉样式 | 悬浮提示 |
|---------|---------|---------|
| i+1 词 | 绿色下划线 | 显示词汇等级，如 "B2 — scrutinize" |
| >i+1 词 | 红色下划线 | 显示词汇等级，如 "C1 — eschew" |
| 已简化词 | 黄色背景块 | 显示原文对照，如 "原文: eschew" |

### 4.3 重写版视图渲染

| 词的类型 | 视觉样式 | 悬浮提示 |
|---------|---------|---------|
| 已简化词 | 黄色背景块 | 显示原文对照，如 "原文: eschew" |
| 普通词 | 无特殊样式 | 无 |

## 5. 技术实现要点

### 5.1 API 设计

**新端点：** `POST /api/llm/filter-and-simplify-words`

**请求体：**
```json
{
  "sentence": "原文全文",
  "words": ["候选词1", "候选词2"],
  "word_levels": {"候选词1": "B2", "候选词2": "C1"},
  "target_level": "B2",
  "user_level": "B1"
}
```

### 5.2 数据存储

IndexedDB 新增字段：
- `validI1Words`: string[] — 有效 i+1 词列表
- `validAboveI1Words`: string[] — 有效 >i+1 词列表
- `removedWords`: {word, reason}[] — 被过滤的词
- `wordLevels`: object — DeepSeek 判断的等级

### 5.3 渲染组件

**ArticlePanel 核心逻辑：**
1. 根据 `validI1Words` 判断绿色下划线
2. 根据 `validAboveI1Words` 判断红色下划线
3. 根据 `rewriteMappings` 判断黄色背景块
4. 重写版视图直接使用替换后的文本

## 6. 验收标准

### 功能验收
- [ ] 用户粘贴文章后，系统正确识别 i+1 和 >i+1 词汇
- [ ] DeepSeek 能够过滤词典误标的简单词
- [ ] DeepSeek 将 >i+1 词重写为 i+1 水平的词/短语
- [ ] 原文视图正确显示绿色/红色下划线和黄色背景块
- [ ] 重写版视图显示简化后的全文
- [ ] 悬浮提示正确显示原文对照
- [ ] 历史记录支持视图切换，状态正确保存

### 视觉验收
- [ ] 绿色下划线：表示 i+1 可学习词汇
- [ ] 红色下划线：表示 >i+1 需简化词汇
- [ ] 黄色背景块：表示已简化的词汇，悬浮显示原文
- [ ] 两种视图之间可以自由切换

---

## 7. 边界情况处理

1. **无候选词**：文章过于简单，没有 i+1 或 >i+1 词汇 → 提示用户，保留原文
2. **全部过滤**：DeepSeek 判断所有词都过于简单 → 保留原文，提示用户
3. **部分简化失败**：某些 >i+1 词无法找到合适的 i+1 替换 → 使用原文或短语义近似的表达
4. **视图切换**：切换视图后，之前选中的词汇状态保持
