## Tasks

### Task 1: Create subtitle parser utility

Create `frontend/src/features/reading/inputAdapters/subtitleParser.js`:

Parses SRT and VTT formats to clean text:
- Detect format: VTT starts with `WEBVTT`, SRT has numeric sequence + timestamp pattern
- Strip SRT: sequence numbers (digits-only lines), timestamps (`HH:MM:SS,ms --> HH:MM:SS,ms`), blank lines
- Strip VTT: `WEBVTT` header, cue identifiers, timestamps (`HH:MM:SS.ms --> HH:MM:SS.ms`), `NOTE` blocks
- Remove HTML tags: `<i>`, `<b>`, `<font>`, `<c>`, `<ruby>`, etc.
- Remove speaker labels: `[Speaker]:` or `(Speaker):` patterns
- Join consecutive lines that don't end with sentence-final punctuation (`.`, `?`, `!`) — D-09 rule
- Collapse 3+ blank lines into double newline (paragraph break)
- Return: `{ text: string, format: 'srt' | 'vtt' | 'unknown' }`

Export: `parseSubtitle(fileContent: string): { text: string, format: string }`

### Task 2: Create API client for extract endpoints

Create `frontend/src/shared/api/extractApi.js`:

```javascript
// URL extraction
export async function extractUrl(url) // POST /api/extract/url → { text, title }
// OCR extraction  
export async function extractOcr(imageFile) // POST /api/extract/ocr (multipart) → { text, confidence }
```

Use `client.js` auth pattern (Authorization: Bearer token header). Handle error responses with `parseResponse()` helper.

### Task 3: Create input adapter components

Create `frontend/src/features/reading/inputAdapters/` directory with 4 adapter components:

**UrlAdapter.jsx** — URL input tab content:
- URL text input field with placeholder "https://example.com/article"
- "提取" button — calls `extractUrl(url)`, then calls `onSubmit(text, { type: 'url', sourceUrl: url, title })`
- Inline error display below field (not toast) per D-12
- Loading state with spinner during extraction

**PdfAdapter.jsx** — PDF upload tab content:
- File dropzone/button for PDF files (accept=".pdf", max 10MB — enforce client-side)
- Uses `pdf.js` (`pdfjs-dist` package) to extract text in browser
  - Dynamic import: `const pdfjsLib = await import('pdfjs-dist')`
  - Set worker: `pdfjsLib.GlobalWorkerOptions.workerSrc = new URL('pdfjs-dist/build/pdf.worker.mjs', import.meta.url).href`
  - Extract all pages text, join with double newlines
- Calls `onSubmit(text, { type: 'pdf', filename: file.name, pageCount: N })`
- Inline error per D-13: "无法解析该 PDF 文件" / "该 PDF 为扫描件" (if text === '')
- **Check if pdfjs-dist is installed:** `cat frontend/package.json | grep pdfjs` — if not found, add to package.json dependencies

**SubtitleAdapter.jsx** — Subtitle upload tab content:
- File input (accept=".srt,.vtt", max 2MB)
- Uses `subtitleParser.js` to parse client-side
- Calls `onSubmit(text, { type: 'subtitle', filename: file.name, format: 'srt'|'vtt' })`
- Inline error per D-14: "无法解析字幕文件格式"

**OcrAdapter.jsx** — Image OCR tab content:
- File input (accept="image/*", max 5MB)
- Show image preview after selection
- Show "消耗 X 积分" confirmation before extraction (static text — D-20, check billing rate from API if available, else hardcode "5 积分")
- Confirm button → calls `extractOcr(imageFile)` → `onSubmit(text, { type: 'ocr', filename: file.name })`
- Inline error per D-15: "图片识别失败，请确保图片清晰且包含英文文字"
- Low confidence warning if `confidence < 0.7`
