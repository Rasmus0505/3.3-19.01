# Phase 39 Plan 01: Multi-Modal Input Adapters

## Objective

Extend the existing reading pipeline input area with four new input sources:
网页链接 (URL extraction), PDF, 字幕 (SRT/VTT), 图片OCR — all converging to the same
`onSubmit(text)` pipeline call. Adds a tab bar above the existing textarea in
`LeftPanel.jsx`, client-side parsers for PDF and subtitle, two new server endpoints
for URL extraction and OCR, and sourceMetadata tracking in history.

## Context

- `@frontend/src/features/reading/LeftPanel.jsx` — extend with tab bar
- `@frontend/src/features/reading/HistoryPanel.jsx` — add source label/icon
- `@frontend/src/features/reading/readingRewriteDB.js` — schema unchanged (sourceMetadata passed through history)
- `@app/api/routers/llm.py` — add extract router registration
- `@app/main.py` — register new extract router
- `@.planning/phases/39-multi-modal-input-pipeline/39-CONTEXT.md` — all decisions D-01 to D-20

## Tasks

### Task 1: 前端标签栏 + 文本/字幕/PDF 输入 UI (client-side only)
type="auto"

Add tab bar to `LeftPanel.jsx` with tabs: 文本 (default), 网页链接, PDF, 字幕, 图片OCR.
- Tab state ephemeral (not persisted). Default tab = "文本".
- 文本 tab: existing textarea + confirm button (unchanged).
- 字幕 tab: file dropzone accepting .srt / .vtt. Client-side parse with subtitle util.
- PDF tab: file dropzone accepting .pdf (max 10MB). Client-side extract with pdfjs-dist.
- 网页链接 tab: URL input field + extract button (calls backend /api/extract/url).
- 图片OCR tab: image dropzone accepting images (max 5MB). Calls backend /api/extract/ocr.
All tabs call the same `onSubmit(text, sourceMetadata)` (extend signature to carry metadata).

Create `frontend/src/features/reading/inputAdapters/subtitleParser.js` — SRT/VTT parser (client-side).
Install `pdfjs-dist` package. Create `frontend/src/features/reading/inputAdapters/pdfExtractor.js`.

### Task 2: 后端 URL 提取 API
type="auto"

Create `app/api/routers/extract.py`:
- `POST /api/extract/url` — requires auth JWT, accepts `{ url }`, fetches page with httpx,
  extracts article text using trafilatura (add to requirements.txt), returns `{ text, title }`.
- Rate: lightweight, no balance charge.
- Error: 422 if url malformed, 400 if extracted text < 50 chars, 502 on fetch failure.

### Task 3: 后端 OCR API
type="auto"

Add to `app/api/routers/extract.py`:
- `POST /api/extract/ocr` — requires auth JWT, accepts multipart image upload (max 5MB),
  calls DashScope vision/OCR API (qwen-vl-plus or similar), deducts user balance,
  returns `{ text, confidence }`.
- Uses existing DashScope infra pattern from `app/infra/`.
- Balance deduction uses existing billing service pattern.
- Error messages: 402 on insufficient balance, 400 on oversized file, 503 on API failure.

### Task 4: 注册 extract router + 前端 API client
type="auto"

- Register extract router in `app/main.py`.
- Create `frontend/src/features/reading/api/extractApi.js` with `extractUrl(url, token)` and `extractOcr(file, token)` calls.
- HistoryPanel: add source icon/label display (D-11): small text label based on `sourceMetadata.type` from history record.
- Extend `saveHistoryRecord` call sites to include `sourceMetadata` in history record.

### Task 5: 构建并同步到 app/static
type="auto"

Run `npm run build:app-static` in `frontend/` to build and sync to `app/static/`.
Verify `app/static/index.html` updated timestamp.
