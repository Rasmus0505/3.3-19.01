# 33-01: CSS — Yellow Block Highlight + Tooltip Timing

## Objective
Replace the amber underline on `.rewrite-highlight` with a full yellow background block; ensure tooltip appears/disappears within 200ms.

## Context
The existing `.rewrite-highlight` uses `border-bottom` (underline style). Decisions D-01 through D-05 specify a background-color block with specific padding, border-radius, and oklch color. Decisions D-06 through D-08 and D-16 specify 200ms tooltip transition timing. Decision D-09 specifies that the blue selection accent overlays the yellow block when both are active.

## Tasks

### Task 1: Replace `.rewrite-highlight` underline with background block

<read_first>
- `frontend/src/features/reading/reading.css` (lines 384–429 — existing `.rewrite-highlight` and `.rewrite-tooltip`)
</read_first>

<action>
In `frontend/src/features/reading/reading.css`, find the block at lines 386–391 (`.article-content .article-word.rewrite-highlight`) and replace the entire declaration block with:

```css
.article-content .article-word.rewrite-highlight {
  background-color: oklch(0.93 0.16 85);
  padding: 4px 8px;
  border-radius: 4px;
  color: oklch(0.20 0.02 85);
  cursor: pointer;
  position: relative;
}
```

This applies: full block background (D-01), 4px/8px padding (D-02), 4px radius (D-03), warm yellow oklch color (D-04), and removes the amber underline that previously replaced CEFR underlines (D-05).
</action>

<acceptance_criteria>
- [ ] `grep -n "rewrite-highlight" frontend/src/features/reading/reading.css` shows `background-color: oklch(0.93 0.16 85)` on the `.rewrite-highlight` rule
- [ ] `grep -n "padding:" frontend/src/features/reading/reading.css` (within rewrite-highlight block) shows `padding: 4px 8px`
- [ ] `grep -n "border-radius" frontend/src/features/reading/reading.css` (within rewrite-highlight block) shows `border-radius: 4px`
- [ ] `grep -n "border-bottom" frontend/src/features/reading/reading.css` does NOT appear inside the `.rewrite-highlight` block (underline is removed)
</acceptance_criteria>

### Task 4: Add selection + rewrite overlay (blue on yellow)

<read_first>
- `frontend/src/features/reading/reading.css` (lines 351–354 — existing `.article-word--selected`)
- Same file (lines 386–391 — new `.rewrite-highlight` block from Task 1)
</read_first>

<action>
Add a new CSS rule after the existing `.article-word--selected` block (after line 354) to handle the additive case described in D-09 and D-15:

```css
/* Selection accent layered on top of yellow rewrite block */
.article-content .article-word--selected.rewrite-highlight {
  background-color: oklch(0.93 0.16 85);
  box-shadow: inset 0 0 0 2px oklch(0.65 0.18 175);
}
```

This keeps the yellow background as the base layer and adds a blue inner border as the selection accent.
</action>
