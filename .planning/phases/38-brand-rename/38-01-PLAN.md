# Plan 38-01: Logo 替换 + HTML 元数据

## Objective

将 `BottleMark.tsx`（瓶子图标）替换为 `UnlockMark.tsx`（开锁图标），创建 favicon，并更新 HTML 标题和 Open Graph 元数据。完成后，用户在浏览器标签页、登录页面会看到 Unlock 品牌图标，不再有瓶子图标。

## Threat Model

<threat_model>
**Risk Level:** Low — no authentication, no user input handling, no API changes, no database queries.

**Changes scope:** SVG component swap, HTML meta tag additions, favicon file creation.

**Threats considered:**
- T-38-01: SVG injection via favicon/icon — MITIGATED: SVG is static hardcoded asset, no user-provided content
- T-38-02: OG image tag pointing to external URL — MITIGATED: og:image omitted from scope; og:title and og:description are static strings

**No security-sensitive code is modified in this plan.**
</threat_model>

```tsx
import React from "react";

interface UnlockMarkProps {
  size?: number;
  className?: string;
  title?: string;
}

export function UnlockMark({
  size = 44,
  className,
  title = "Unlock Anything",
}: UnlockMarkProps) {
  return (
    <svg
      viewBox="0 0 64 64"
      role="img"
      aria-label={title}
      width={size}
      height={size}
      className={className}
      fill="none"
      xmlns="http://www.w3.org/2000/svg"
    >
      <rect x="2" y="2" width="60" height="60" rx="20" fill="url(#unlock-bg)" />
      {/* Lock body */}
      <rect x="18" y="30" width="28" height="22" rx="5" fill="#ECFEFF" stroke="#155E75" strokeWidth="2.4" />
      {/* Shackle — open padlock arc (open on upper-right) */}
      <path
        d="M22 30 L22 22 C22 15.4 27 11 32 11 C37 11 42 15.4 42 22"
        stroke="#0F172A"
        strokeWidth="4"
        strokeLinecap="round"
        fill="none"
      />
      {/* Keyhole circle */}
      <circle cx="32" cy="39" r="4" fill="#0EA5A4" />
      {/* Keyhole stem */}
      <rect x="30" y="42" width="4" height="5" rx="1" fill="#0EA5A4" />
      <defs>
        <linearGradient id="unlock-bg" x1="10" y1="6" x2="56" y2="60" gradientUnits="userSpaceOnUse">
          <stop stopColor="#0F766E" />
          <stop offset="0.52" stopColor="#0EA5A4" />
          <stop offset="1" stopColor="#67E8F9" />
        </linearGradient>
      </defs>
    </svg>
  );
}
```
</action>
