# Plan 38-02: 字符串替换（上传界面 + 管理界面）

## Objective

将所有用户可见的 "Bottle 1.0" / "Bottle 2.0" 字符串替换为 "Unlock 本地" / "Unlock 云端"，覆盖上传界面、错误消息和管理界面。完成后，用户在生成流程、错误提示和管理后台中不再看到任何 "Bottle" 字样。

## Threat Model

<threat_model>
**Risk Level:** Low — pure string literal replacements, no logic changes, no API modifications.

**Changes scope:** User-visible string constants and UI labels only.

**Threats considered:**
- T-38-02-01: Breaking billingDisplayRank sort in AdminRatesTab — MITIGATED: display_name rename in asrModels.js AND sort keys in AdminRatesTab.jsx are changed in the same plan/task (Task 38-02-06)
- T-38-02-02: Error message changes causing confusion — MITIGATED: messages preserve meaning, only brand name changes

**No security-sensitive code is modified in this plan.**
</threat_model>
