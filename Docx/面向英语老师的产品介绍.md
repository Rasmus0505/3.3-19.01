# Bottle — 智能 i+1 阅读学习平台

## 什么是 i+1？

**i+1** 是语言习得理论中的核心概念：

> **i** = 你当前的英语水平  
> **i+1** = 略高于你水平的"可理解输入"（最有效的学习内容）

**关键原理**：学习发生在遇到"陌生但不至无法理解"的时刻。

- **i+0**：太简单，没有新东西
- **i+2 以上**：太难，寸步难行
- **i+1**：刚刚好，跳一跳能够到

---

## 问题：如何找到"刚好比自己难一点"的阅读材料？

大多数英语学习者面临这样的困境：

> "这篇文章太难了，但我不知道该简化哪里。"

比如一段新闻原文：
> "The phenomenon is **ubiquitous** in modern **metropolises**, causing **exacerbated** congestion."

对中级学习者来说，每个实词都是生词，根本读不下去。

传统做法：找"简单文章"（但内容可能很无聊），或逐词查词典（效率太低）。

## Bottle 的解决方案：AI 驱动的 i+1 阅读

Bottle 结合 **CEFR 权威词汇表** 与 **AI 智能重写**，让任何文章都变成"刚好适合你"���学习材料。

### 第一步：精准识别你的 i+1 词汇

Bottle 内置 50,000+ 词的 CEFR 难度等级库，可以分析任意英文文章，标注每个词的难度：

```
原文：The phenomenon is ubiquitous in modern metropolises.

CEFR 标注：
The [A1] phenomenon [B2] is [A1] ubiquitous [C2] in [A1] modern [B1] metropolises [C1].
```

- **绿色**：你认识的词（i 范围内）
- **黄色/橙色/红色**：超出你水平的词（i+1 或更高）

### 第二步：AI 把 i+2 变成 i+1

点击"简化文章"，AI 会：

> 识别超出你水平的词 → 用你认识的基础词汇替换 → 保留原文意思

```
原文：The phenomenon is ubiquitous in modern metropolises.

简化版：This thing is found everywhere in big cities.

对照（悬停查看）：
- phenomenon → thing        (C2 → A1)
- ubiquitous → found everywhere (C2 → B1)
- metropolises → big cities   (C1 → A2)
```

简化后的文章：
- 保留了原文的核心内容和语境
- 全部换成你能理解的表达
- 黄色色块标注简化处，鼠标悬停可看原词对照

### 第三步：在真实语境中学习

阅读时：
- **点击**任意单词查看翻译
- **收藏**想记住的词加入生词本
- **复习**时回到原文语境回想原词

**学习闭环**：简化阅读 → 学习新表达 → 回归原文理解 → 巩固记忆
