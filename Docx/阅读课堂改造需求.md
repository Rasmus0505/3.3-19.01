# 阅读课堂改造需求

## 背景与问题

现有阅读板块的「课堂」模式存在以下问题：

- 课程结构固定为 8 个场景，不论文章长短都一样，内容节奏感差
- 第一个场景「进入课堂」是纯废话，用户体验差
- 老师 TTS 一口气念完所有台词，无停顿，用户听完不知道在讲什么
- Canvas 区域内容和老师讲解无视觉绑定，声音和画面脱节
- 底部 Roundtable 占用空间过大，挤压阅读区
- 字体、颜色、对比度不符合沉浸式阅读标准

## 改造目标

将阅读课堂从「固定 8 场景的自动播放器」改造为「动态分节的沉浸式阅读引导课堂」，核心体验是：**用户主导节奏，AI 根据文章结构和用户困惑点动态生成讲解**。

---

## 核心概念：动态分节课程

### 分节规则

- 后端生成课程时，LLM 按**自然段落**对文章分节
- 每节对应文章的一个或多个自然段落（以语义完整性为准）
- 若某段落超过 250 词，自动拆为两节
- 课程阶段数 = 节数 × 4（每节固定走 阅读→讲解→做题→讨论 四步）
- 短文（2-3 段）约 8-12 个阶段；长文（5-6 段）约 16-24 个阶段

### 每节的四个阶段

```
节 N
├── 阶段 1：阅读（用户静默自读）
├── 阶段 2：讲解（AI 动态生成，spotlight 聚焦词语）
├── 阶段 3：做题（1-2 道针对本节的题目）
└── 阶段 4：讨论（可跳过，开放问答）
```

进度感：界面顶部显示「第 N 节 / 共 M 节」及当前阶段名称。

## 阶段一：阅读

### 界面布局

```
┌──────────────────────────────────────────┐
│  第 1 节 / 共 3 节    [阅读]              │  ← 顶部状态栏
├──────────────────────────────────────────┤
│                                          │
│  [文章摘要：本节主要讲述...]              │  ← AI 生成的本节摘要（1-2 句）
│                                          │
│  ──────────────────────────────────────  │
│                                          │
│  Technology has changed the way we       │  ← 改写后的文章段落
│  learn. The ability to [perusing→reading]│    黄色高亮 = 被改写的词
│  long texts requires practice...         │
│                                          │
│                                          │
├──────────────────────────────────────────┤
│  [Coach Mira]  正在等你阅读完成...        │  ← 底部 Roundtable（最小化状态）
│                          [开始讲解 →]    │
└──────────────────────────────────────────┘
```

### 文章排版规范

- 字体：`"Iowan Old Style", "Palatino Linotype", Palatino, serif`（参考 pretext demo 字体栈）
- 字号：18px，行高：30px
- 列宽：最大 680px，左右居中
- 背景：纯白（亮色模式）/ 深灰（暗色模式）
- 段落间距：1.5em

### 改写词高亮交互

- 所有被 i+1 改写替换的词，用**黄色底色**高亮标记（`background: oklch(0.95 0.12 85)`）
- Hover 黄色高亮词 → 显示 tooltip：
  ```
  ┌─────────────────────┐
  │ 原词：perusing      │
  │ 等级：B2            │
  │ 改写原因：超出目标  │
  └─────────────────────┘
  ```
- tooltip 不遮挡阅读区主体

### 词语点击卡片

用户点击文章中**任意词语**（不限于高亮词），底部弹出小卡片：

```
┌────────────────────────────────┐
│  reading                  [B1] │  ← 词 + CEFR 等级
│  /ˈriːdɪŋ/                    │  ← 音标（可选，若有）
│  ────────────────────────────  │
│  认真地阅读；仔细研读           │  ← LLM 实时生成的简短释义（中文）
│  ────────────────────────────  │
│  [+ 加入生词本]  [查词典 →]    │  ← 两个操作
└────────────────────────────────┘
```

- 卡片从底部滑入，不遮挡文章主体（`position: fixed; bottom: 200px`）
- 释义由 LLM 实时生成（调用现有 `/api/llm/...` 端点）
- 点击卡片外部关闭
- 卡片宽度约 280px，字体紧凑

### 划选工具条

用户划选文字（单词或短句）→ 出现浮动工具条（参考 Medium/Kindle 选中工具条）：

```
[不懂这里] [+ 生词本] [查词典]
```

- **「不懂这里」**：将划选内容标记为用户困惑点，存入本节困惑列表
- 困惑点在文章中以淡蓝色下划线标记，让用户知道已记录
- 困惑列表在阅读阶段结束时传给后端，用于生成个性化讲解

### 阅读阶段结束

- 底部显示**「开始讲解 →」**按钮（始终可见）
- 用户点击后：前端将本节困惑词列表发给后端，触发讲解内容实时生成
- 生成期间显示 loading（「Coach Mira 正在准备讲解...」）约 3-5 秒
- 生成完成后自动进入讲解阶段

## 阶段二：讲解

### 核心机制

- 讲解内容**实时生成**（进入讲解阶段时触发，非课程预生成）
- 后端接收：本节文章文本 + 用户困惑词列表 + 默认重点词
- 后端返回：讲解 actions 列表（spotlight 目标词 + 对应台词 + TTS）
- 讲解重点：困惑词优先讲，不足时用 AI 默认选取的重点词补充，总计 2-3 个词

### Spotlight 机制

老师讲某个词时，文章里对应词语产生**聚焦高亮动画**：

- 目标词：CSS 动画（外发光 + 轻微放大 + 边框闪烁）
- 其余文字：轻度变暗（opacity: 0.4）
- 动画持续至该词讲解结束，自动恢复

Actions 序列节奏（单个词的讲解流程）：
```
1. spotlight 聚焦目标词（视觉先到）
2. 停顿 0.6 秒
3. TTS 老师开口讲解（2-3 句）
4. 停顿 1.5 秒（用户消化）
5. spotlight 消失
6. 进入下一个词
```

### 讲解阶段界面

- 阅读界面**不切换**，保持文章显示
- 底部 Roundtable 展开（显示老师头像 + 说话气泡 + 波形动画）
- 右上角显示「跳过讲解」按钮
- 讲解完毕后自动显示「进入做题 →」按钮

---

## 阶段三：做题

### 题目设计

- 每节 1-2 道题，在课程生成时由 LLM 预生成
- 题目类型：单选题（MCQ）为主，可有填空题
- 题目必须与本节内容直接相关（考察理解，非语法）
- 做完立刻显示对错 + 简短解析（1 句）
- 可跳过（右上角「跳过」按钮）

### 界面

- 全屏展示题目卡片，文章退出显示
- 底部 Roundtable 最小化
- 做完题后显示「进入讨论 →」和「跳过讨论，下一节 →」两个按钮

---

## 阶段四：讨论

- 老师主动抛出一个与本节相关的开放问题（ProactiveCard）
- 用户可回答，AI 以老师角色实时响应
- 也可直接点「跳过，下一节 →」
- 讨论为开放问答，用户可追问任何与本节或文章相关的问题

---

## 全局交互规范

### Roundtable 三种状态

| 阶段 | Roundtable 状态 | 高度 |
|------|----------------|------|
| 阅读 | 最小化（仅显示老师名字 + 一行提示） | 56px |
| 讲解 | 展开（老师头像 + 气泡 + 波形） | 160px |
| 做题 | 最小化 | 56px |
| 讨论 | 完全展开（含用户输入框） | 192px |

### 字体与颜色规范（参考 OpenMAIC）

- 阅读正文：`Iowan Old Style` serif，18px，#1a1a1a
- 界面元素：`Geist` sans-serif（项目已有）
- 主色调：紫色 `var(--primary)`
- 改写高亮：黄色 `oklch(0.95 0.12 85)`
- 困惑标记：蓝色下划线 `oklch(0.65 0.15 230)`
- 气泡背景（老师）：`oklch(from var(--primary) l c h / 0.06)` + 紫色边框
- 气泡背景（学生）：`oklch(0.55 0.15 230 / 0.06)` + 蓝色边框
- 气泡文字：14px，行高 1.6，`var(--foreground)`（当前对比度不足，需加深）

### 删除的内容

- 删除原来的「进入课堂（entry）」场景，课堂直接从阅读阶段开始
- 删除原来固定 8 场景结构（entry/preview/guided_reading/deep_explain/checkpoint/discussion/output/wrap_up）

## 后端 API 变更

### 新增：课程生成 v3 schema

后端生成课程时输出：

```json
{
  "schema_version": 3,
  "sections": [
    {
      "id": "section-1",
      "title": "The Problem of Distraction",
      "paragraph_range": [0, 1],
      "rewritten_text": "...",
      "summary": "本节讲述注意力分散的现代问题...",
      "default_spotlight_words": ["nevertheless", "cognitive"],
      "quiz": [
        {
          "type": "single",
          "question": "...",
          "options": [...],
          "answer": "B",
          "analysis": "..."
        }
      ]
    }
  ],
  "participants": [...],
  "rewrite_mappings": [...],
  "word_definitions": {
    "reading": { "definition": "认真地阅读", "cefr": "B1" }
  }
}
```

### 新增：讲解内容实时生成端点

`POST /api/llm/reading-course/generate-explain`

请求：
```json
{
  "section_id": "section-1",
  "section_text": "...",
  "confused_words": ["nevertheless", "cognitive load"],
  "default_spotlight_words": ["nevertheless", "cognitive"],
  "target_level": "B1",
  "teacher_persona": "Coach Mira"
}
```

响应：
```json
{
  "actions": [
    {
      "type": "spotlight",
      "target_word": "nevertheless",
      "sentence_hint": "Nevertheless, many people find themselves trapped"
    },
    {
      "type": "speech",
      "speaker": "teacher",
      "text": "Let's look at 'nevertheless' here. It signals a contrast..."
    },
    {
      "type": "pause",
      "duration_ms": 1500
    }
  ]
}
```

### 新增：词语释义端点

`POST /api/llm/reading-course/word-definition`

请求：`{ "word": "perusing", "context_sentence": "...", "target_level": "B1" }`

响应：`{ "definition": "认真地阅读；仔细研读", "cefr": "B2", "phonetic": "/pəˈruːzɪŋ/" }`

## 实施阶段

### Phase 1：阅读阶段（基础体验）

- 新的 v3 课程生成（动态分节）
- `ReadingSection.jsx`：改写词高亮 + hover tooltip + 词语点击卡片
- `SelectionToolbar.jsx`：划选「不懂这里」功能
- `SectionProgress.jsx`：节进度显示
- Roundtable 最小化状态
- 删除 entry 场景

**验收**：进入课堂直接看到文章，黄色高亮词 hover 显示原文，点击词语弹出释义卡片，可以标记困惑词

### Phase 2：讲解阶段（spotlight + 实时生成）

- 后端新增 `generate-explain` 端点
- `ExplainSection.jsx` + `SpotlightWord.jsx`
- 讲解阶段实时生成 actions + TTS
- Roundtable 160px 展开状态
- 节奏控制（spotlight → 停顿 → 说话 → 停顿）

**验收**：点「开始讲解」→ loading 3-5 秒 → 老师开始说话 → 文章中对应词语高亮聚焦 → 有停顿感

### Phase 3：做题 + 讨论 + 全局打磨

- `QuizSection.jsx` + `DiscussSection.jsx`
- 后端新增 `word-definition` 端点（词语卡片释义）
- Roundtable 动画过渡三种状态
- 字体、颜色、间距全面对标 OpenMAIC 规范
- 词语释义 LLM 接入

**验收**：完整走完一篇文章的所有节，体验流畅，字体排版舒适
