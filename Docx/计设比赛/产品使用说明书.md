## 1. 产品概述

### 1.1 产品简介

Unlock Anything 是一款 AI 驱动的英语精听学习平台。用户可以将任意英语音视频素材（YouTube、B站、播客、本地文件等）导入平台，系统自动完成：

- **语音识别（ASR）**：将音频转录为带时间戳的英文字幕
- **机器翻译**：逐句生成中文译文
- **AI 讲解**：对难句自动生成解释、简化版本及音频讲解
- **词汇分析**：按 CEFR 等级标注每句中的词汇
- **音频切片**：自动提取每句对应的音频片段

学习者可以在精听界面中逐句播放、跟读、练习拼写、查看 AI 讲解，并通过间隔重复系统持续巩固词汇。

### 1.2 主要功能模块

| 模块 | 功能摘要 |
|------|----------|
| 课程生成 | 从音视频文件或公开链接一键创建精听课程 |
| 精听学习 | 逐句播放、AI 讲解、进度追踪 |
| 口语评测（SOE） | 跟读录音，获得发音评分 |
| 练习模式 | 拼写、听写、词汇填空等交互练习 |
| 阅读理解 | AI 辅助阅读文章，自动出题 |
| 生词本 | 间隔重复算法管理个人词库 |
| 学习仪表盘 | 数据统计、AI 学习教练、每日目标 |
| 钱包系统 | 积分余额、充值码兑换、消费明细 |
| 管理员后台 | 用户管理、计费配置、系统监控 |

### 1.3 适用场景

- **个人学习者**：利用感兴趣的英语内容（TED、播客、影视）做精听训练
- **语言老师**：将课程素材导入平台，分享给学生使用
- **机构管理员**：批量管理用户、配置服务费率、分发充值码

### 1.4 支持的终端

| 终端 | 访问方式 |
|------|----------|
| 网页浏览器 | 直接访问平台网址（Chrome / Edge / Firefox） |
| Windows 桌面客户端 | 下载安装 Bottle Desktop（含本地 ASR 模型） |
| 移动端 | 浏览器访问（响应式布局） |

## 2. 快速开始

### 2.1 注册账号

1. 打开平台网址，点击右上角 **注册**
2. 填写邮箱、用户名、密码（至少 8 位）
3. 点击 **创建账号**，完成注册
4. 系统会自动为新账号分配初始积分余额

> **提示：** 系统默认将您的英语水平设为 B1（中级），可在 [个人设置](#32-修改个人信息) 中调整。

### 2.2 创建第一个课程

**方式一：上传本地文件**

1. 点击导航栏 **课程** → **新建课程**
2. 点击上传区域，选择音视频文件（MP4、WAV、MP3 等）
3. 填写课程标题（可选，系统会自动从文件名提取）
4. 选择 ASR 模型（默认使用云端 Qwen3 ASR Flash）
5. 点击 **开始生成**，等待处理完成（通常 1–5 分钟）

**方式二：导入公开链接**（需桌面客户端）

1. 打开 Bottle 桌面客户端
2. 在导入栏粘贴公开视频链接（YouTube / B站 / 播客等）
3. 系统自动下载并解析标题
4. 点击 **生成课程**，完成后自动跳转到学习界面

> **注意：** 仅支持公开单条链接，不支持需要登录、会员权限的内容。

### 2.3 开始学习

1. 进入课程列表，点击已就绪的课程
2. 课程播放界面将显示：
   - 左侧：音频/视频播放器
   - 右侧：逐句字幕列表（英文 + 中文）
3. 点击某句可跳转到该句时间点并播放
4. 点击 **AI 讲解** 图标查看难句解释
5. 点击句子旁的 **已学** 按钮标记学习进度

## 3. 账号与个人设置

### 3.1 登录与登出

- **登录**：输入注册邮箱和密码，点击 **登录**
- **Token 刷新**：系统自动刷新登录状态，无需频繁重新登录
- **登出**：点击右上角头像 → **退出登录**

### 3.2 修改个人信息

进入 **设置** → **个人资料** 可修改：

| 字段 | 说明 |
|------|------|
| 用户名 | 显示名称，全局唯一 |
| 邮箱 | 登录凭证，修改后需重新登录 |
| 密码 | 当前密码验证后方可修改 |
| CEFR 等级 | 设置后影响词汇分级显示和练习难度 |

### 3.3 CEFR 等级说明

系统使用欧洲语言共同参考框架（CEFR）将词汇分为 6 个等级：

| 等级 | 描述 |
|------|------|
| A1 | 入门：最基础词汇 |
| A2 | 基础：日常用语 |
| B1 | 中级：标准水平（默认） |
| B2 | 中高级：较丰富词汇 |
| C1 | 高级：高阶词汇 |
| C2 | 精通：接近母语水平 |

设置您的等级后，系统会：
- 在精听界面突出显示超出您当前等级的词汇
- 在练习中优先安排这些词汇进行强化训练
- 生成课程时使用该等级作为分析基准

## 4. 课程管理

### 4.1 课程状态说明

| 状态 | 含义 |
|------|------|
| 处理中 | ASR、翻译、分析正在进行 |
| 就绪 | 课程已生成完毕，可以学习 |
| 失败 | 处理过程出错，可查看详情或重试 |
| 已归档 | 课程被手动归档，不在默认列表显示 |

### 4.2 创建课程详细步骤

#### 上传文件

1. 点击 **新建课程** → 选择 **上传文件**
2. 支持格式：
   - 视频：MP4、WebM、MKV
   - 音频：WAV、MP3、FLAC、OGG
   - 文件大小上限：200 MB
3. 选择 **ASR 模型**：
   - **云端 Qwen3 ASR Flash**（推荐）：速度快，识别准确率高，消耗积分
   - **本地 Faster Whisper Medium**：无需积分，但需要桌面客户端并下载本地模型
   - **本地 Faster Whisper Distil Small**：速度最快，精度略低
4. 点击 **生成课程**

> **积分消耗说明：** 云端 ASR 按音频时长计费，机器翻译按 token 数计费，AI 讲解生成按 LLM token 计费。详见 [钱包与积分系统](#10-钱包与积分系统)。

#### 处理流程说明

系统后台按以下顺序自动处理：

```
上传文件
  ↓ 音频提取（视频转音频）
  ↓ 音频分段（>5 分钟自动分段）
  ↓ ASR 转录（生成带时间戳的句子）
  ↓ 机器翻译（英文 → 中文）
  ↓ CEFR 词汇分析
  ↓ 难句检测与 AI 讲解生成
  ↓ 音频切片（为每句提取独立音频）
  ↓ 课程就绪
```

### 4.3 查看课程列表

- 进入 **课程** 页面，所有课程按创建时间倒序排列
- 每张课程卡片显示：标题、状态、时长、创建时间
- 点击课程卡片进入学习界面

### 4.4 删除课程

1. 在课程列表或课程详情页，点击 **更多操作** → **删除**
2. 确认后，课程及其所有关联数据（字幕、音频、进度）将被永久删除

> **警告：** 删除操作不可撤销。

## 5. 学习功能详解

### 5.1 精听界面布局

进入课程后，精听界面分为三个区域：

```
┌─────────────────────────────────────────────────────┐
│                    媒体播放器                         │
│           （音频波形 / 视频画面）                      │
├──────────────────┬──────────────────────────────────┤
│   字幕句子列表    │         当前句详情面板             │
│                  │  英文原句                          │
│  ① 第一句        │  中文译文                          │
│  ② 第二句 ◀     │  CEFR 词汇高亮                     │
│  ③ 第三句        │  AI 讲解（可展开）                  │
│  ...             │  简化版本                          │
│                  │  [跟读评测] [标记已学]              │
└──────────────────┴──────────────────────────────────┘
```

### 5.2 句子操作说明

#### 播放控制

| 操作 | 效果 |
|------|------|
| 点击句子 | 跳转到该句时间点并播放 |
| 循环播放按钮 | 在该句时间区间内反复播放 |
| 上一句 / 下一句 | 跳转相邻句子 |
| 播放速度 | 0.5× / 0.75× / 1.0× / 1.25× / 1.5× |

#### 字幕显示控制

| 选项 | 说明 |
|------|------|
| 显示英文 | 开/关英文字幕 |
| 显示中文 | 开/关中文译文 |
| CEFR 高亮 | 用颜色标注超出您当前等级的词汇 |

### 5.3 AI 讲解功能

对于系统判定为"需要讲解"的复杂句子，句子旁会出现 **AI 讲解** 标记。展开后包含：

- **简化版本**：将原句改写为更易理解的表达
- **关键词讲解**：对难词、短语进行逐一解释
- **讲解音频**：AI 生成的语音讲解（可播放）
- **句子结构分析**（部分句子）

### 5.4 进度追踪

- 点击句子旁的 **已学** 按钮，将该句标记为已掌握
- 课程进度条实时更新已学句数 / 总句数
- 进度数据与账号绑定，多设备同步

### 5.5 课程内问答（Lesson Chat）

在精听界面右下角点击 **AI 问答** 图标，可以就当前课程内容提问：

- 询问某个句子的语法结构
- 请求对某个表达的更多例句
- 提问文化背景或专业词汇含义

> **提示：** AI 问答有上下文记忆，可以进行多轮追问。消耗 LLM 积分。

## 6. 练习与测评

### 6.1 练习模式说明

在课程学习界面或独立练习入口，提供以下练习类型：

#### 拼写练习

- 系统播放该句音频
- 用户在输入框中打出英文句子
- 系统高亮显示拼写错误的单词
- 记录正确率和尝试次数

#### 听写练习

- 遮盖英文字幕
- 播放音频后手动输入听到的内容
- 适合提升听力和书写能力

#### 词汇填空

- 从句子中随机隐去若干词汇
- 根据上下文和音频填写正确单词
- 难度根据 CEFR 等级自动调整

### 6.2 口语发音评测（SOE）

Unlock Anything集成了腾讯 SOE（Speech of English）引擎，提供专业发音评分。

**使用步骤：**

1. 在精听界面，点击目标句子旁的 **跟读** 按钮
2. 点击 **开始录音**，跟读该句英文
3. 录音结束后，系统在数秒内返回评分
4. 查看评分维度：

| 评分维度 | 说明 |
|----------|------|
| 流利度（Fluency） | 语速是否自然，停顿是否合适 |
| 准确度（Accuracy） | 发音是否准确 |
| 完整度（Completeness） | 是否完整说出句子内容 |
| 综合评分 | 加权总分（满分 100） |

5. 查看具体单词的发音问题标注
6. 历史评分记录可在 [学习仪表盘](#9-学习仪表盘) 中查看

> **注意：** SOE 评测需要麦克风权限。首次使用时浏览器会弹出权限请求，请点击允许。

### 6.3 练习数据记录

每次练习的结果自动记录：

- 尝试次数
- 正确率
- 完成时间
- 连续练习天数（Streak）

这些数据用于仪表盘统计和 AI 教练的个性化建议。

## 7. 阅读理解（多 Agent 协作课堂）

阅读模块采用了创新的**多 Agent 协作学习框架**。系统不仅提供文本，还会构建一个虚拟课堂，包含负责引导和讲解的 **AI 教师 (Coach Mira)**、负责辅助解释的 **AI 助教 (Noah)**，以及提出问题的 **AI 同学 (Lily/Max)**，共同陪伴您完成段落式的沉浸阅读。

### 7.1 创建阅读课程

1. 进入 **阅读** 模块，点击 **新建阅读包**
2. 输入文章 URL（平台会自动提取正文内容），或直接粘贴文章文本
3. 系统自动分析文章难度，并基于您的 CEFR 等级生成适配的阅读材料
4. 点击 **生成阅读课程**

### 7.2 四阶段学习流程

进入生成的阅读课程后，您将体验到完整的四阶段闭环学习流程（Read → Explain → Quiz → Discuss）：

#### 阶段一：静默阅读 (Read)
- **自适应文本**：阅读匹配您当前水平的文本。
- **困惑标记**：在阅读过程中，您可自由高亮标记不懂的单词或长难句，这些标记会实时传递给接下来的 AI 教师。

#### 阶段二：动态讲解 (Explain)
- **Agent 聚焦讲解**：AI 教师 (Coach Mira) 登场，优先针对您刚刚标记的困惑词汇进行讲解，或主动解释预设的核心词汇。
- **上下文释义**：结合文章当前文脉（而非词典定义）进行讲解，配有语音播报（TTS），并在阅读材料上提供高亮聚焦（Spotlight）效果。

#### 阶段三：理解测验 (Quiz)
- **多题型检查**：系统针对当前段落自动生成单选题（MCQ）、填空题或排序题。
- **即时反馈**：作答后立即显示得分及详尽的解析。

#### 阶段四：师生圆桌讨论 (Discuss)
- **多 Agent 互动表演**：界面底部呈现“圆桌舞台（Roundtable）”。AI 教师与 AI 同学将围绕刚才阅读的段落，自动展开 3-5 轮中英双语讨论，为您提供真实的场景语境。
- **用户实时加入**：您可以随时加入圆桌，向 AI 教师提问文章逻辑、探讨深层含义或请求背景知识补充。AI 将带着完整的上下文记忆与您展开实时对话。

## 8. 生词本与词汇系统

### 8.1 词汇来源

生词可以通过以下方式加入生词本：

| 来源 | 操作方式 |
|------|----------|
| 精听课程 | 点击字幕中高亮词汇 → 添加到生词本 |
| 阅读理解 | 点击词汇卡片 → 加入生词本 |
| 手动添加 | 在生词本页面 → 手动输入单词 |

### 8.2 生词本界面

进入 **生词本** 页面可以：

- 查看所有收藏词汇（按添加时间 / CEFR 等级排序）
- 查看每个词的定义、例句来源
- 查看记忆分数和下次复习时间
- 手动标记为已掌握或删除

### 8.3 间隔重复复习

Unlock Anything 使用基于艾宾浩斯遗忘曲线的间隔重复算法：

- **记忆分数**（0–100）：反映当前对该词的熟悉程度
- **下次复习时间**：根据记忆分数自动安排
- **复习间隔**：
  - 首次学习 → 1 天后复习
  - 答对 → 间隔拉长（最长 30+ 天）
  - 答错 → 间隔缩短，重新强化

### 8.4 词汇闪卡

1. 在生词本页面点击 **生成闪卡**
2. 系统自动生成词汇卡片（含单词、释义、例句、发音）
3. 进行卡片翻转练习
4. 每次练习结果更新记忆分数

### 8.5 CEFR 词汇统计

在 **生词本** → **统计** 中查看您的词汇分布：

- 各 CEFR 等级已掌握词汇数量
- 折线图显示词汇量增长趋势
- 与同等级学习者的对比（如有数据）

## 9. 学习仪表盘

### 9.1 仪表盘概览

进入 **仪表盘** 页面，显示您的学习全貌：

| 模块 | 内容 |
|------|------|
| 学习概况 | 总课程数、已学句子数、练习时长 |
| 每日目标 | 今日完成进度 / 设定目标 |
| 连续天数 | 连续学习天数记录 |
| AI 教练 | 个性化学习建议 |
| 发音趋势 | SOE 评分随时间的变化图表 |
| 词汇进度 | CEFR 等级词汇掌握进度 |

### 9.2 AI 教练

点击 **获取学习建议** 后，AI 教练会基于您的：

- 近期练习成绩
- 发音评分趋势
- 词汇掌握情况
- CEFR 水平

生成个性化建议，例如：

> "您过去一周在 B2 级词汇练习中错误率较高，建议重点复习 academic vocabulary 词组。今日目标：完成 2 课精听 + 20 个生词复习。"

### 9.3 学习计划

在仪表盘中设置 **每日学习目标**：

- 精听句子数
- 词汇复习数量
- 练习时长（分钟）

系统会在每日目标完成后发出祝贺提示。


> **提示：** 使用本地 ASR 模型（需桌面客户端）不消耗积分。

## 14. 技术规格与限制

### 14.1 文件上传限制

| 参数 | 限制 |
|------|------|
| 最大文件大小 | 200 MB |
| 支持视频格式 | MP4、WebM、MKV |
| 支持音频格式 | WAV、MP3、FLAC、OGG |
| 单次处理最长时长 | 建议不超过 60 分钟 |

### 14.2 处理性能参考

| 音频时长 | 预计处理时间（云端 ASR） |
|----------|--------------------------|
| 5 分钟 | 1–2 分钟 |
| 15 分钟 | 3–5 分钟 |
| 30 分钟 | 6–10 分钟 |
| 60 分钟 | 15–20 分钟 |

> 以上时间为参考值，实际处理时间受服务器负载影响。

### 14.3 浏览器兼容性

| 浏览器 | 支持情况 |
|--------|----------|
| Chrome 100+ | 完全支持（推荐） |
| Edge 100+ | 完全支持 |
| Firefox 100+ | 支持（SOE 功能需检查麦克风权限设置） |
| Safari 15+ | 基本支持（部分音频功能可能有差异） |
| 移动端浏览器 | 基本支持（建议使用 Chrome for Mobile） |

### 14.4 网络要求

- 使用云端 ASR / LLM 功能需要稳定的互联网连接
- 建议带宽：上传 ≥ 5 Mbps（上传文件时）
- 本地 ASR 模式（桌面端）可在无网络状态下完成转录

### 14.5 数据安全

- 用户密码使用 bcrypt 加密存储，平台无法获取原始密码
- 登录凭证使用 JWT Token，有效期内自动续期
- 上传的媒体文件存储在平台服务器，不对外公开
- 管理员操作全部记录在审计日志中
