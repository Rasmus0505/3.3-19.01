## T-1 自动语音识别（ASR）技术

### 技术定位

ASR 是平台内容生产的起点——将任意英语音视频转录为带时间戳的逐句文本，支撑后续所有功能。

### 双线路架构

平台部署了两套并行 ASR 线路，互为补充：

#### Bottle 1.0：本地化 Faster Whisper

| 参数 | 值 |
|------|-----|
| 模型 | `faster-whisper-distil-small.en` / `faster-whisper-medium` |
| 部署方式 | 本地服务器 / 桌面客户端 |
| 计算类型 | INT8 量化（CPU 推理） |
| 积分消耗 | 无（本地免费） |
| 适用场景 | 离线使用、隐私敏感、节省成本 |

Faster Whisper 是 OpenAI Whisper 模型的高效 C++ 实现（CTranslate2 框架），在保持识别精度的同时，推理速度约为原版的 4 倍，内存占用减少 50%。

#### Bottle 2.0：云端 Qwen3 ASR Flash

| 参数 | 值 |
|------|-----|
| 模型 | `qwen3-asr-flash-filetrans` |
| 部署方式 | DashScope API（云端） |
| 精度 | 高（支持标点、句级切分） |
| 积分消耗 | 按音频分钟计费 |
| 适用场景 | 高精度需求、长音频批处理 |

### 分段处理机制

对长音频，系统自动分段处理，避免单次请求超时：

```
音频时长 ≤ 300 秒 → 单次转录
音频时长 > 300 秒 → 自动按静音点切割（搜索窗口 45 秒）
                  → 多段并行转录
                  → 时间戳合并输出
```

### 输出格式

```json
{
  "segments": [
    {
      "begin_ms": 1200,
      "end_ms": 4800,
      "text": "The phenomenon is found everywhere in modern big cities."
    }
  ]
}
```

每条 segment 包含毫秒级精度的开始/结束时间戳，是后续音频切片的定位依据。

## T-2 CEFR 词汇分级系统

### 技术定位

这是平台"i+1 自适应"的量化引擎，将抽象的"难度匹配"转化为可计算、可操作的词汇等级标注。

### 词汇表规格

平台内置 **CEFR-J 词汇表（v1.5）**：

| 属性 | 数值 |
|------|------|
| 词条总数 | 50,000+ |
| 来源 | CEFR-J 项目（东京外国语大学・投野由纪夫教授团队） |
| 人工验证比例 | 84.4% |
| 覆盖等级 | A1 / A2 / B1 / B2 / C1 / C2 |
| 标注内容 | 词形、词性、CEFR 等级 |

### 分析流程

```
输入文本
  ↓ 分词（tokenization）
  ↓ 词形还原（lemmatization）
  ↓ 逐词查表匹配 CEFR 等级
  ↓ 生成词汇难度分布：
    {A1: 45%, A2: 30%, B1: 15%, B2: 7%, C1: 2%, C2: 1%}
  ↓ 与学习者设定等级比对
  ↓ 标注超出等级的词汇（高亮展示）
```

### 与 i+1 的对应关系

| 词汇等级 | 相对于 B1 学习者的地位 |
|----------|----------------------|
| A1、A2 | i-1（已掌握，可跳读） |
| B1 | i（当前水平） |
| **B2** | **i+1（目标习得区间）** |
| C1、C2 | i+2（暂时搁置，待 AI 简化） |

## T-3 大语言模型（LLM）教学引擎

### 技术定位

LLM 是平台从"内容转录工具"升级为"智能教学系统"的核心技术。

### 主力模型

| 模型 | 用途 | 调用方式 |
|------|------|----------|
| DeepSeek V3.2（标准模式） | 词汇简化、翻译、解析 | DashScope API |
| DeepSeek V3.2（扩展思维模式） | 高质量阅读材料生成 | DashScope API |
| Qwen3 Vision Flash | OCR / 图文理解 | DashScope API |
| Qwen MT Flash | 专业机器翻译 | DashScope API |

### 六大教学功能模块

#### 功能 1：i+1 词汇简化（`llm_sentence.py`）

将超出学习者等级的词汇替换为目标等级词汇：

> **原句（C1 词汇）：** "The phenomenon is ubiquitous in modern metropolises."
>
> **简化后（B1 学习者）：** "The phenomenon is **found everywhere** in modern **big cities**."

- `ubiquitous`（C2）→ `found everywhere`（B1）
- `metropolises`（C1）→ `big cities`（A2）

系统同时保留原句，以对照高亮形式呈现，支持学习者在理解的基础上逐步接触原文。

#### 功能 2：句子语法解析（`llm_sentence.py`）

对复杂句子生成结构分析：
- 句子成分拆解（主谓宾、状语从句等）
- 关键词组讲解
- 中文释义与使用场景

#### 功能 3：个性化阅读材料生成（`llm_reading.py`）

基于学习者当前生词本，生成包含目标词汇的阅读短文，确保：
- 词汇密度适中（生词占比约 5-8%）
- 话题贴合学习者兴趣
- 难度精确锁定在 i+1 区间

#### 功能 4：理解测验生成（`llm_quiz.py`）

阅读或课程完成后自动生成多选题：
- 题目考查文章主旨、细节、词义
- 每题附带答案解析
- 难度与文章等级匹配

#### 功能 5：讨论对话脚本（`llm_discussion.py`）

生成阅读文章的开放性讨论问题，引导学习者：
- 用英语表达观点
- 关联个人经验
- 进行更高阶的语言运用

#### 功能 6：词汇例句生成（`llm_vocabulary.py`）

为生词本中的单词生成额外例句：
- 不同语境下的多个例句
- 搭配提示（collocations）
- 近义词对比

### LLM 与理论对应关系总览

| 功能 | 理论依据 | 核心主张 |
|------|----------|----------|
| i+1 词汇简化 | Krashen（1985）可理解输入假说 | 学习发生于 i+1 输入 |
| 句子语法解析 | Swain（1995）元语言反思功能 | 反思语言形式深化习得 |
| 个性化阅读材料 | Nation（2001）语境化词汇习得 | 词汇需在语境中多次相遇 |
| 理解测验生成 | Willis（1996）TBLT 语言焦点 | 任务后形式聚焦练习 |
| 讨论脚本 | Long（1996）意义协商互动假说 | 互动促进意义理解与习得 |
| 词汇例句生成 | Nation（2022）多次语境相遇 | 多语境接触丰富词汇知识 |

## T-4 语音合成（TTS）与声音克隆

### 标准 TTS

平台为以下内容自动生成语音：

- 词汇卡片发音

1. 上传 30 秒以上的声音样本

此功能的教学意义在于降低 TTS 声音的陌生感，增加学习者与学习内容的情感关联。

## T-5 发音评估（SOE）

### 技术实现

集成腾讯 SOE（Speech of English Assessment）API，实现音素级发音评估：

**评估流程：**
```
学习者录音（WebAudio API）
  ↓ 音频编码（WAV 16kHz 单声道）
  ↓ 上传至 Tencent SOE API
  ↓ 与参考文本比对（音素级对齐）
  ↓ 返回评分报告
```

**返回评分维度：**

| 维度 | 计算依据 | 范围 |
|------|----------|------|
| 综合评分 | 加权平均 | 0-100 |
| 流利度（Fluency） | 语速、停顿、连读 | 0-100 |
| 准确度（Accuracy） | 音素正确率 | 0-100 |
| 完整度（Completeness） | 读出词汇比例 | 0-100 |

同时返回每个单词的发音状态标注（正确/可接受/错误），支持精细化反馈展示。

## T-6 间隔重复系统（SRS）

### 算法核心

基于 Ebbinghaus 遗忘曲线的间隔重复调度算法：

```
memory_score (0.0 ~ 1.0) — 当前记忆强度
  ↓
next_review_at = now + f(memory_score, review_count, wrong_count)
```

**调度规则：**

| 记忆强度 | 复习间隔 |
|----------|----------|
| 0.0-0.2（新词/遗忘） | 1 天 |
| 0.2-0.4（模糊记忆） | 3 天 |
| 0.4-0.6（中等记忆） | 7 天 |
| 0.6-0.8（较好记忆） | 14 天 |
| 0.8-1.0（牢固记忆） | 30+ 天 |

答对 → `memory_score` 增加，间隔拉长  
答错 → `memory_score` 降低，间隔缩短，触发补救复习

### 词汇状态层级

```
active（新加入）→ learning（复习中）→ mastered（已掌握）→ archived（长期保留）
```

### 语境保留设计

每个生词保存其原始来源（`source_lesson_id`、`source_sentence_id`），复习时可查看该词在原文中的完整句子，实现语境化复习而非孤立词表记忆。

## 第一档：输入理论（Input Theories）

---

### 理论 1｜Krashen 可理解输入假说

**文献来源：**
> Krashen, S. D. (1982). *Principles and practice in second language acquisition*. Pergamon Press.  
> Krashen, S. D. (1985). *The input hypothesis: Issues and implications*. Longman.
>
> 被引次数：~18,000+（1982 版）、~10,000+（1985 版）  
> 免费全文：https://sdkrashen.com/content/books/principles_and_practice.pdf

**理论原文（核心表述）：**

Krashen 在 1985 年的著作中明确写道：

> "We acquire language in only one way — when we understand messages, i.e. when we understand what people say to us or what we read. In other words, we acquire when we understand language that contains structure a bit beyond our current level of competence." *(Krashen, 1985, p. 2)*

即：

> **i + 1 原则**：语言习得发生于学习者接触的输入语言 *i* 略高于其当前水平，即满足 *i + 1* 条件之时。

**监控模型五大假说：**

```
┌─────────────────────────────────────────────────────────┐
│                  Krashen 监控模型 (1982)                  │
├─────────────────┬───────────────────────────────────────┤
│ 假说 1          │ 习得-学习假说（Acquisition-Learning）   │
│                 │ 习得（Acquisition）= 隐性自然接触       │
│                 │ 学习（Learning）= 显性语法学习          │
│                 │ → 只有习得驱动流利输出                  │
├─────────────────┼───────────────────────────────────────┤
│ 假说 2          │ 监控假说（Monitor Hypothesis）          │
│                 │ 显性知识仅作为事后监控工具使用           │
├─────────────────┼───────────────────────────────────────┤
│ 假说 3          │ 自然顺序假说（Natural Order）           │
│                 │ 语法特征习得有可预测的自然顺序           │
├─────────────────┼───────────────────────────────────────┤
│ 假说 4  ★核心   │ 输入假说（Input Hypothesis）            │
│                 │ 习得 = 可理解输入 = i + 1               │
├─────────────────┼───────────────────────────────────────┤
│ 假说 5          │ 情感过滤假说（Affective Filter）        │
│                 │ 高焦虑 → 过滤器激活 → 阻碍习得          │
│                 │ 低焦虑+高动机 → 过滤器开放 → 促进习得   │
└─────────────────┴───────────────────────────────────────┘
```

**平台实现：**

1. **CEFR 词汇标注**：内置 50,000+ 词条的 CEFR-J 词汇表，对任意文本逐词标注 A1-C2 等级
2. **AI 自适应简化**：LLM 将 i+2 及以上词汇替换为 i+1 词汇，使原文动态适配学习者水平
3. **情感过滤对策**：
   - 无"读不懂"的失败体验（AI 先处理再呈现）
   - 发音评估采用连续评分（非二元对错）
   - 界面设计强调"进步感"而非"失败惩罚"

### 理论 2｜Schmidt 注意假说

**文献来源：**
> Schmidt, R. (1990). The role of consciousness in second language learning. *Applied Linguistics, 11*(2), 129–158. https://doi.org/10.1093/applin/11.2.129
>
> 被引次数：~6,000+  
> 免费 PDF：https://www.nflrc.hawaii.edu/PDFs/SCHMIDT%20The%20role%20of%20consciousness%20in%20second%20language%20learning.pdf

**理论原文（核心表述）：**

> "Noticing is the necessary and sufficient condition for the conversion of input to intake. **You have to notice something in the input for it to become intake.**" *(Schmidt, 1990, p. 132)*

即：只有被学习者"注意到"的语言特征，才可能真正被纳入习得系统（Input → Intake）。

**注意的三个层次：**

```
层次 1 — 注意（Noticing）：有意识地感知到某个语言特征的存在
层次 2 — 注意到缺口（Noticing the Gap）：对比自身语言与目标语之间的差距
层次 3 — 理解（Understanding）：对语言特征的规律性进行元认知分析
```

**平台实现：**

- **CEFR 高亮标注**：用颜色编码突出超出学习者等级的词汇，强制引导"注意"
- **词汇点击查看**：降低获取词义的成本，鼓励主动注意不认识的词
- **拼写练习**：书写输出迫使学习者精确注意词形，激活"注意缺口"机制
- **发音错误标注**：SOE 评测在音素级标注错误位置，引导学习者注意发音缺口

### 理论 3｜Vygotsky 最近发展区（ZPD）与脚手架

**文献来源：**
> Vygotsky, L. S. (1978). *Mind in society: The development of higher psychological processes*. Harvard University Press.
>
> 被引次数：~100,000+（教育心理学最高被引著作之一）

**理论原文（核心表述）：**

> "The zone of proximal development is the distance between the actual developmental level as determined by independent problem solving and the level of potential development as determined through problem solving under adult guidance or in collaboration with more capable peers." *(Vygotsky, 1978, p. 86)*

脚手架（Scaffolding）由 Wood, Bruner & Ross (1976) 基于 ZPD 概念发展而来，定义为：

> "Those elements of the task that are initially beyond the learner's capacity, thus permitting him to concentrate upon and complete only those elements that are within his range of competence." *(Wood et al., 1976, p. 90)*

**ZPD 与 i+1 的对比：**

```
Vygotsky ZPD：
  实际发展水平 ←————————————→ 潜在发展水平
  （独立能完成）     ZPD       （专家辅助下能完成）

Krashen i+1：
       i ←———→ i+1
  （当前水平）（目标习得区）

两者高度一致：都强调在"略超当前水平"处提供挑战与支持
```

**平台实现（脚手架机制）：**

| 脚手架类型 | 平台功能 |
|------------|----------|
| 内容难度支架 | AI 将原文简化至 i+1 水平，保留原文供对照 |
| 语义支架 | 词汇点击即查翻译和释义 |
| 结构支架 | AI 句子解析拆解语法结构 |
| 情感支架 | 积分、进度条、掌握状态给予持续正反馈 |
| 逐步撤除 | 随学习者等级提升，高亮词汇自然减少（无需手动调整） |

### 理论 4｜Swain 可理解输出假说

**文献来源：**
> Swain, M. (1985). Communicative competence: Some roles of comprehensible input and comprehensible output in its development. In S. Gass & C. Madden (Eds.), *Input in second language acquisition* (pp. 235–253). Newbury House.  
> Swain, M. (1995). Three functions of output in second language learning. In G. Cook & B. Seidlhofer (Eds.), *Principle and practice in applied linguistics* (pp. 125–144). Oxford University Press.
>
> 被引次数：~7,000+（1985）、~5,000+（1995）

**理论原文（核心表述）：**

Swain（1985）观察加拿大法语沉浸式教育项目，发现即使学生接受了大量可理解输入，其口语和写作产出仍远低于母语者水平。她由此提出：

> "Comprehensible output may be necessary for the development of complete grammatical competence... **Pushed output** is necessary in order to develop full communicative competence." *(Swain, 1985, p. 248)*

Swain（1995）归纳输出的三大功能：

**功能 1：注意/触发功能（Noticing Function）**

> "In producing the target language, learners may notice a gap between what they want to say and what they can say, leading them to recognize some of their linguistic problems."

**功能 2：假设检验功能（Hypothesis-Testing Function）**

> "Output may also function as a way of trying out new language forms and structures... getting feedback on whether or not these are correct, or whether or not they communicate the intended meaning."

**功能 3：元语言反思功能（Metalinguistic Function）**

> "The metalinguistic function of output... enables learners to control and internalize linguistic knowledge."

**平台实现：**

### 理论 5｜Long 互动假说

**文献来源：**
> Long, M. H. (1996). The role of the linguistic environment in second language acquisition. In W. C. Ritchie & T. K. Bhatia (Eds.), *Handbook of second language acquisition* (pp. 413–468). Academic Press. https://doi.org/10.1016/B978-012589042-7/50015-3
>
> 被引次数：~6,000+

**理论原文（核心表述）：**

> "**Negotiation for meaning**, and especially negotiation work that triggers interactional adjustments by the NS or more competent interlocutor, facilitates acquisition because it connects input, internal learner capacities, particularly selective attention, and output in productive ways." *(Long, 1996, p. 451-452)*

**意义协商的三种互动策略：**

```
确认核查（Confirmation Checks）：
  说话者确认对方是否理解自己
  例："Do you mean that...?" / "Is that right?"

澄清请求（Clarification Requests）：
  说话者请求对方重述或解释
  例："Sorry, could you say that again?" / "What do you mean by...?"

理解核查（Comprehension Checks）：
  说话者主动检查对方是否理解
  例："OK?" / "Does that make sense?"
```

**互动假说的逻辑链：**

```
交际障碍（Communication Breakdown）
  ↓ 触发意义协商（Negotiation of Meaning）
  ↓ 互动调整（Interactional Modifications）
  ↓ 输入变为可理解（Comprehensible Input）
  ↓ 引导注意语言形式（Attention to Form）
  ↓ 触发习得（Acquisition）
```

**平台实现：**

- **课程 AI 问答（`/api/lesson_chat`）**：学习者就课程内容提问，AI 根据问题复杂度自适应调整解释深度，模拟意义协商中"更有能力的对话者"角色
- **AI 阅读讨论**：AI 以"讨论伙伴"身份响应学习者，通过确认核查和追问引导语言产出
- **AI 句子解析（`/api/llm/explain-sentence`）**：针对学习者"不理解"的句子提供形式导向的显性反馈，对应互动中的澄清请求功能

### 理论 6｜认知负荷理论（CLT）

**文献来源：**
> Sweller, J. (1988). Cognitive load during problem solving: Effects on learning. *Cognitive Science, 12*(2), 257–285. https://doi.org/10.1207/s15516709cog1202_4
>
> 被引次数：~10,000+  
> DOI 访问：https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog1202_4

**理论原文（核心表述）：**

基于 Miller（1956）"工作记忆容量有限（7±2 个组块）"这一认知事实，Sweller 提出：

> "The total cognitive load imposed by a task consists of intrinsic load (due to the nature of the material being learned), extraneous load (due to the manner in which the material is presented), and germane load (the load that contributes to the formation of schemas and automaticity)." *(Sweller et al., 1998, p. 259)*

**三类认知负荷：**

```
┌────────────────────────────────────────────────────────────┐
│                工作记忆（Working Memory）                    │
│                     容量有限 ≈ 7±2 组块                     │
│                                                            │
│  内在负荷           外在负荷           相关负荷              │
│ (Intrinsic)       (Extraneous)       (Germane)             │
│                                                            │
│  任务本身的复杂性   不良教学设计引起    图式建构与自动化       │
│  不可完全消除       应尽量减少          应尽量最大化          │
│                                                            │
│  ←——————————————总负荷 ≤ 工作记忆上限——————————————→        │
└────────────────────────────────────────────────────────────┘
```

**Mayer & Moreno（2003）的 9 项降低认知负荷原则（部分）：**

| 原则 | 内容 | 平台对应 |
|------|------|----------|
| 分段原则（Segmenting） | 将内容分成小块而非连续呈现 | 句级字幕分割，独立音频片段 |
| 模态原则（Modality） | 语言说明配图优于纯文字 | 视频画面+同步字幕+音频三通道 |
| 冗余原则（Redundancy） | 避免重复的文字-声音信息 | 字幕与解析分层展示，非重叠堆砌 |
| 信号原则（Signaling） | 用高亮等视觉信号引导注意 | CEFR 颜色高亮标注词汇难度 |

**平台实现：**

- **i+1 词汇简化**：直接降低内在认知负荷——学习者不再需要处理大量生词，认知资源可投入语篇层面的意义建构
- **句级切割**：每句独立音频 + 循环播放，遵循分段原则，避免持续输入导致工作记忆饱和
- **AI 讲解分块呈现**：词汇解释以"词 → 释义 → 例句"的结构化格式呈现，遵循减少分散注意效应原则

### 理论 7｜多媒体学习认知理论（CTML）

**文献来源：**
> Mayer, R. E. (2009). *Multimedia learning* (2nd ed.). Cambridge University Press. https://doi.org/10.1017/CBO9780511811678
>
> 被引次数：~20,000+（各版本合计）

**理论原文（核心表述）：**

CTML 的三个基本假设：

> **1. 双通道假设（Dual-Channel Assumption）：**
> "Humans possess separate channels for processing visual/pictorial and auditory/verbal material."
>
> **2. 容量有限假设（Limited Capacity Assumption）：**
> "Each channel can process only a limited amount of material at a time."
>
> **3. 主动加工假设（Active Processing Assumption）：**
> "Meaningful learning occurs when learners engage in appropriate cognitive processing during learning, including paying attention to relevant words and pictures, mentally organizing the selected words and pictures into coherent representations, and mentally integrating those representations with prior knowledge." *(Mayer, 2009, p. 61)*

**双通道信息加工模型：**

```
外部信息
  ↓
┌──────────────────────────────────────────────────────────┐
│  眼睛 → [图像/文字] ──选择──→ 图像模型 ──整合──→         │
│                                               ↓          │
│                                          先验知识         │
│                                               ↑          │
│  耳朵 → [声音/语言] ──选择──→ 语音模型 ──整合──→         │
└──────────────────────────────────────────────────────────┘
         感觉记忆         工作记忆            长时记忆
```

**多媒体原则（Multimedia Principle）：**

> "People learn more deeply from words and pictures than from words alone." *(Mayer, 2009, p. 223)*

Montero Perez 等人（2015）的实证研究证实：

> "Full captions led to significantly better listening comprehension scores than keyword captions and no-caption conditions."

**平台实现：**

沉浸式精听界面（ImmersiveLessonPage）实现了三通道协同：

```
视频画面（视觉内容通道）
  +
同步字幕（视觉语言通道）—— 颜色高亮标注 CEFR 等级
  +
音频流（听觉语言通道）
  =
三通道协同多模态输入 → 最大化双通道利用率
```

阅读模式支持：文章文本 + 词汇卡片（VocabCardsPanel）+ AI 句子解析（AnalysisPanel）并行，满足不同感知偏好。

### 理论 8｜双重编码理论

**文献来源：**
> Paivio, A. (1990). *Mental representations: A dual coding approach*. Oxford University Press.

**理论原文（核心表述）：**

> "The DCT [Dual Coding Theory] assumes that cognition involves the activity of two functionally independent but interconnected subsystems: a verbal system specialized for dealing with language and a nonverbal (imagery) system specialized for dealing with nonverbal objects and events." *(Paivio, 1990, p. 53)*

当信息通过言语系统和意象系统同时编码时：

> "Items that are associated with both verbal and imaginal codes are better recalled than items with only one code, and both are better recalled than items with neither code." *(Paivio, 1990, p. 82)*

这就是**"双重编码优势"**——同时具有言语和图像记忆痕迹的信息，提取更容易、记忆更持久。

**平台实现：**

- 字幕视频中，视频内容（图像记忆）与语言字幕（言语记忆）同步呈现，形成双重编码

- CEFR 颜色高亮将词汇难度等级视觉化，为抽象的语言知识增加视觉编码通道

| 对抗无聊感 | 内容由学习者自选，真实性和趣味性远超课本 |

### 理论 10｜Zhao（2025）生成式 AI 学习认知评价模型

**文献来源：**

Advance online publication. https://doi.org/10.1080/17501229.2025.2551120

**研究背景：**

来自香港科技大学语言教育中心，基于 503 名中国大学英语学习者的实证研究，以非正式数字英语学习（IDLE）为情境，将认知评价理论与技术接受模型（TAM）整合，探究生成式 AI 持续使用意愿的心理机制。

**核心路径模型：**

```
                                         ┌→ 感知有用性（Perceived Usefulness）→┐
语言学习控制评价 ────────────────────────┤→ 感知易用性（Perceived Ease of Use）→┤→ 积极情绪 → 持续使用意愿
```

> 3. 外在价值评价显著正向预测感知风险，间接负向影响持续使用意愿

**对平台设计的直接启示：**

> 系统需通过**降低感知风险**（简化使用路径、减少错误惩罚）和**强化控制感评价**（精准匹配难度、提供明确进度反馈）来提升学习者积极情绪，进而维持持续使用意愿。

**平台实现（与研究发现的对应）：**

|----------|--------------|

| 控制感→降低感知风险 | 学习者掌控内容选择，降低"用错工具"的风险感知 |

### 理论 13｜Nation 词汇习得四链条模型

**文献来源：**
> Nation, I. S. P. (2001). *Learning vocabulary in another language*. Cambridge University Press.  
> Nation, I. S. P. (2022). *Learning vocabulary in another language* (3rd ed.). Cambridge University Press.
>
> Nation 全部著作被引：~82,000+

**理论原文（核心表述）：**

Nation（2001）提出词汇学习的**四链条模型（Four Strands）**：

> "A well-designed language course would consist of four equal strands: **meaning-focused input**, **meaning-focused output**, **language-focused learning**, and **fluency development**." *(Nation, 2001, p. 162)*

**词汇知识的三个层次（原文）：**

> "Knowing a word involves knowing its **form** (spoken and written), its **meaning** (the connection between form and meaning, and its referents), and its **use** (the grammatical functions, collocations, and constraints on use)." *(Nation, 2001, p. 27)*

**"多次语境相遇"原则（原文）：**

> "Research on vocabulary learning suggests that **10 to 20 encounters** with a word in varied contexts are required before it is reliably learned." *(Nation, 2022, p. 94)*

**词汇量与文本理解的关系（Nation & Waring, 1997）：**

| 掌握词汇量 | 文本词汇覆盖率 | 阅读可能性 |
|------------|---------------|------------|
| 1,000 词族 | 约 85% | 困难 |
| 3,000 词族 | 约 95% | 基本可读 |
| 8,000-9,000 词族 | 约 98% | 流畅阅读 |

> "For comfortable reading with only one or two unknown words per page, learners need to know about 8,000–9,000 word families." *(Nation & Waring, 1997, p. 15)*

### 理论 14｜Ebbinghaus 遗忘曲线与间隔重复

**文献来源：**
> Ebbinghaus, H. (1885). *Über das Gedächtnis*. Duncker & Humblot.（英文版 1913 年）  
> Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006). Distributed practice in verbal recall tasks: A review and quantitative synthesis. *Psychological Bulletin, 132*(3), 354–380. https://doi.org/10.1037/0033-2909.132.3.354
>
> Cepeda 元分析被引：~3,500+  
> 免费 PDF：https://escholarship.org/content/qt3rr6q10c/qt3rr6q10c.pdf

**理论原文：**

Ebbinghaus（1885）通过严格控制的自我实验发现遗忘曲线：

> "The curve of forgetting falls steeply at first and then levels off, indicating that most forgetting occurs shortly after learning and that the rate of forgetting decreases over time."

即：记忆痕迹遵循负指数函数衰退：

```
记忆强度 M(t) = e^(−t/S)

其中：t = 距上次学习的时间间隔
     S = 记忆稳定性（随每次成功复习增大）
```

**间隔效应（Spacing Effect）：**

Cepeda 等人（2006）元分析（254 项研究，317 个实验）：

> "Distributed practice produced markedly better long-term retention than massed practice. The advantage of spacing over massing was robust and showed an average effect size of d = 0.46 to 0.80 across studies."

**最优复习间隔（Cepeda et al., 2009）：**

> "The optimal gap [between study and test] was approximately 10–20% of the retention interval... For example, if you want to remember something for one year, you should study it about 1–2 months after the initial learning."

**SRS 与遗忘曲线的对应：**

```
Ebbinghaus 遗忘曲线：
  记忆强度
  ↑   ╲
  │    ╲___
  │        ╲___
  │             ╲___________
  └────────────────────────→ 时间

SRS 复习调度（在遗忘前复习）：
  记忆强度
  ↑   ╲  ↑复习  ╲  ↑复习       ╲  ↑复习
  │    ╲/         ╲/              ╲/
  │
  └────────────────────────→ 时间
  每次复习后记忆强度恢复，且记忆稳定性（S）增大
  → 下次复习间隔可拉长
```

**平台实现：**

平台词汇书（Wordbook）完整实现 SRS 机制：

```python
# 简化版本的调度逻辑
memory_score: float  # 0.0 ~ 1.0，记忆强度
review_count: int    # 已复习次数
wrong_count: int     # 答错次数

# 间隔计算（概念示意）
if memory_score > 0.8:
    next_interval = 30+ days
elif memory_score > 0.6:
    next_interval = 14 days
elif memory_score > 0.4:
    next_interval = 7 days
elif memory_score > 0.2:
    next_interval = 3 days
else:
    next_interval = 1 day

next_review_at = now + next_interval
```

### 理论 15｜自我决定理论（SDT）

**文献来源：**
> Ryan, R. M., & Deci, E. L. (2000). Self-determination theory and the facilitation of intrinsic motivation, social development, and well-being. *American Psychologist, 55*(1), 68–78. https://doi.org/10.1037/0003-066X.55.1.68
>
> 被引次数：~45,000+（全球心理学领域被引最多论文之一）  
> 免费 PDF：https://selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf

**理论原文（核心表述）：**

> "We have proposed three basic psychological needs: **autonomy** (volition and self-endorsement of one's actions), **competence** (feeling effective and capable), and **relatedness** (feeling connected to others). We argue that all three are essential for psychological growth, integrity, and well-being." *(Ryan & Deci, 2000, p. 68)*

**动机内化连续谱（Motivational Continuum）：**

```
外部调节    内摄调节    认同调节    整合调节    内在动机
（外部奖励）（避免羞耻）（认为重要）（融入自我）（本身享受）
←——————————————无自主性——————————————→←——高自主性——→
←————————————外在动机——————————————→   内在动机
```

> "When autonomous motivation underlies behavior, people tend to be more engaged, perform better on complex tasks, show greater creativity, and experience more well-being." *(Ryan & Deci, 2000, p. 71)*

**三个需求与 IDLE（非正式数字英语学习）的天然契合：**

| SDT 需求 | Bottle 平台设计 |
|----------|-----------------|
| **自主性**（Autonomy） | 学习者完全自主选择学习内容（任意 YouTube、播客、文章） |
| **能力感**（Competence） | CEFR 可视化展示词汇成长；SOE 评分提供具体能力证据 |
| **关系性**（Relatedness） | AI 教练、课程问答提供"伴学"陪伴体验；声音克隆可模拟熟悉声音 |

### 理论 16｜Dörnyei 二语动机自我系统（L2MSS）

**文献来源：**
> Dörnyei, Z. (2009). The L2 motivational self system. In Z. Dörnyei & E. Ushioda (Eds.), *Motivation, language identity and the L2 self* (pp. 9–42). Multilingual Matters. https://doi.org/10.21832/9781847691293-003
>
> 被引次数：~5,000+

**理论原文（核心表述）：**

> "The L2 Motivational Self System consists of three components: **(1) Ideal L2 Self** — the L2-specific facet of one's 'ideal self' (if the person we would like to become speaks the L2); **(2) Ought-to L2 Self** — the attributes that one believes one ought to possess to meet expectations and avoid possible negative outcomes; **(3) L2 Learning Experience** — situated, 'executive' motives related to the immediate learning environment and experience." *(Dörnyei, 2009, p. 29)*

**理想 L2 自我的动机机制（原文）：**

> "The Ideal L2 Self is a powerful motivator to learn the L2 because of people's motivation to **reduce the discrepancy between their current and ideal selves**."

**平台实现：**

- **真实媒体内容**作为学习材料，学习者"在真实情境中自然理解英语"的理想 L2 自我形象与日常学习内容高度一致，强化动机愿景的具身感
- **CEFR 等级进阶可视化**为"理想 L2 自我"提供具体化的量化路径（例如：目标是从 B1 达到 B2，需要掌握的词汇量差距可见可量）
- **仪表盘词汇成长曲线**将自我与目标的差距量化呈现，不断缩短的差距强化持续学习动力

### 理论 18｜Warschauer CALL 三阶段历史框架

**文献来源：**
> Warschauer, M. (1996). Computer-assisted language learning: An introduction. In S. Fotos (Ed.), *Multimedia language teaching* (pp. 3–20). Logos International.
>
> 免费全文：http://www.ict4lt.org/en/warschauer.htm

**CALL 三阶段演进（原文框架）：**

```
第一阶段：行为主义 CALL（1960s–1980s）
  理论基础：行为主义（B. F. Skinner）
  特征：重复练习（Drill and Practice）
  代表：PLATO 系统
  局限：机械重复，缺乏真实交际意义

第二阶段：交际主义 CALL（1980s–1990s）
  理论基础：交际语言教学法（CLT）
  特征：意义导向任务、真实交际
  代表：互动软件、语言学习游戏
  局限：个性化程度不足

第三阶段：整合主义 CALL（2000s）
  理论基础：社会文化理论、多媒体学习
  特征：互联网、真实材料、多媒体整合
  代表：语言学习网站、字幕视频
  局限：缺乏动态自适应

第四阶段（新增）：自适应智能 CALL（2020s–）
  理论基础：SLA + 认知科学 + AI
  特征：大语言模型、动态个性化、实时反馈
  代表：Bottle、Duolingo Max
```

Bottle 平台位于第四阶段：以 LLM 为核心引擎，实现真正意义上的动态自适应。

### 理论 19｜Kasneci（2023）LLM 教育机遇与挑战

**文献来源：**
> Kasneci, E., et al. (2023). ChatGPT for good? On opportunities and challenges of large language models for education. *Learning and Individual Differences, 103*, Article 102274. https://doi.org/10.1016/j.lindif.2023.102274
>
> 被引次数：~2,500+（自 2023 年持续快速增长）

**理论原文（机遇部分）：**

> "**Personalization at scale**: LLMs can provide individualized feedback and instructional content to each learner, addressing the long-standing challenge of one-to-one tutoring at scale."
>
> "**Reducing language anxiety**: The non-judgmental, patient nature of AI tutors may help language learners overcome anxiety, consistent with Krashen's affective filter hypothesis."
>
> "**Unlimited practice material**: Unlike human teachers, LLMs can generate an inexhaustible supply of exercises, examples, and explanations tailored to the individual learner's level."

**挑战部分（对平台设计的警示）：**

> "**Hallucinations**: LLMs can generate plausible-sounding but factually incorrect information... [requiring] fact-checking mechanisms."
>
> "**Academic integrity**: The availability of LLMs challenges traditional assessment methods."

**平台的应对策略：**

| LLM 风险 | 平台设计应对 |
|----------|-------------|
| 幻觉（错误信息） | 词汇解释基于 CEFR 词典数据库，而非纯 LLM 生成 |
| 过度依赖 | SRS 系统要求主动复习，不允许纯被动接受 |
| 学术诚信 | 平台为个人学习工具，非作业辅助 |
