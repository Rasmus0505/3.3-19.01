# 不背单词 — 竞品分析报告

> 分析日期：2026年4月 | 分类：国内综合/背词/听说读类

---

## 产品名称

**不背单词**（北京艾斯蓝科技有限公司）

## 产品定位

不背单词是一款以**真实语境沉浸**为核心的英语词汇学习应用，其slogan为"真实语境学单词"。核心差异化在于拥有150万+原声例句（来自影视、纪录片、演讲等真实语料），让用户在原汁原味的语境中自然习得单词，而非死记硬背。面向追求沉浸式学习体验、希望通过真实语境习得词汇的中高级英语学习者。

## 使用流程

1. **注册/登录** → 选择词书 → 设定每日学习计划
2. **单词学习** → 释义 → **原声例句**（影视/纪录片片段）→ 发音 → 搭配词组
3. **语境沉浸** → 每个单词配有多个原声视频例句，用户可观看原声片段理解用法
4. **复习巩固** → 基于遗忘曲线安排复习，复习时再次呈现原声语境
5. **随身听** → 利用碎片时间听单词和例句，通勤/运动场景友好

## 用户体验优点

- **原声例句沉浸感强**：150万+影视原声例句，真实语境远超传统释义例句
- **语境记忆深度高**：在影视场景中学习单词，记忆锚点丰富（画面+声音+情感）
- **搭配词组实用**：提供单词的常用搭配和词组，衔接实际应用
- **界面设计精美**：UI设计简洁优雅，视觉体验在背词类App中属上乘
- **随身听模式**：支持后台播放，通勤运动时可纯听觉复习
- **词根词缀分析**：提供词根词缀拆解，辅助理解构词逻辑

## 用户体验缺点

- **缺乏AI规划**：没有个性化学习路径，学习计划需手动设定
- **无考试题型生成**：不能生成选词填空等考试针对性练习
- **原声例句加载慢**：视频例句需要网络加载，弱网环境体验差
- **存储占用大**：原声视频资源占用手机存储空间较大
- **免费功能受限**：核心原声例句观看有次数限制，需会员解锁
- **新词学习效率低**：沉浸式学习每个单词耗时较长，不适合追求高效率的备考用户

## 内容资源特点

- **词库规模**：覆盖主流考试词书，数量中等
- **原声例句**：150万+条原声例句，来源包括TED演讲、BBC纪录片、好莱坞电影、美剧英剧等
- **搭配词组**：每个单词配有常用搭配，衔接实际应用
- **词根词缀**：提供词根词缀拆解和解析
- **视听资源**：支持视频和音频两种模式的原声例句呈现

**商业模式**：以原声例句为核心付费点的免费增值模式

## 人工智能结合

- **基础遗忘曲线复习**：基于艾宾浩斯遗忘曲线安排复习周期
- **语境匹配**：将单词与原声例句进行基础匹配，但算法简单
- **AI能力评价**：AI能力较弱，缺乏个性化学习路径、智能语境生成、考试题型生成等高级功能。与扇贝2024年AI升级后的差距较大

## 与其他竞品相比的优势

1. **原声例句最丰富**：150万+条原声例句，来源权威、场景真实，行业独一
2. **语境沉浸感最强**：影视原声带来的画面+声音+情感多维度记忆锚点，记忆深度远超纯文本
3. **界面设计最优**：UI/UX设计在背词类App中属于第一梯队
4. **搭配词组实用**：衔接"记忆"与"应用"，帮助用户从"认识单词"到"会用单词"
5. **随身听模式创新**：后台播放+碎片时间利用，学习场景拓展

## 借鉴点

1. **真实语境学习**：原声例句证明了"在真实语境中习得词汇"比死记硬背更有效，记忆深度更高
2. **视听多模态输入**：视频+音频+文字的多模态学习，记忆锚点更丰富
3. **搭配词组衔接应用**：从"记住词义"到"会用搭配"的过渡设计
4. **随身听场景拓展**：利用碎片时间进行被动输入，降低学习时间成本

## 存在问题

1. **学习效率偏低**：沉浸式学习每个单词耗时较长，与备考用户"高效刷词"的需求矛盾
2. **AI能力薄弱**：缺乏智能规划和个性化学习，停留在"展示语境"的层面
3. **存储和网络依赖**：原声视频资源占用存储大、需要网络加载
4. **考试适配差**：缺乏题型训练和真题语境，备考用户难以深度依赖
5. **产品生态缺失**：没有配套的阅读、听力等生态产品，单打独斗

## 总结

不背单词以"真实语境学单词"的差异化定位，在百词斩的图片联想和墨墨的算法记忆之外开辟了第三条路径。150万+原声例句带来的沉浸式学习体验确实令人印象深刻，记忆深度也远超纯文本学习。然而，学习效率偏低、AI能力薄弱、考试适配差等问题限制了其受众范围。对Bottle English而言，不背单词证明了**真实语境学习**的价值——影视原声、纪录片片段等真实语料比人造例句更有效。但我们也需要解决其效率问题：**通过AI智能筛选最匹配的语境片段，在沉浸感和学习效率之间找到平衡**。
