# 雅思哥 — 竞品分析报告

> 分析日期：2026年4月 | 分类：考试/工具型类

---

## 产品名称

**雅思哥**（广州启德教育/雅思哥团队）

## 产品定位

雅思哥是国内最权威的雅思考试备考工具和社区，定位为"雅思官方合作伙伴，专注雅思口语预测超过15年"。核心价值是提供当季口语题库、写作预测、机考模拟等雅思备考核心资源，同时拥有活跃的考生社区。是雅思考生几乎必装的备考工具。

## 使用流程

1. **注册/登录** → 选择考试类型（A类/G类）和考试日期
2. **口语题库** → 查看/练习当季口语话题（Part 1/2/3）
3. **写作预测** → 查看写作话题预测和范文
4. **机考模拟** → 1:1还原真实机考界面的模拟考试
5. **AI口语测评** → 录音练习 → AI评分反馈
6. **社区交流** → 在考生社区分享经验和获取资讯

## 用户体验优点

- **口语题库最权威**：当季口语话题更新最快最全，雅思备考必备
- **机考模拟1:1还原**：界面与真实考试完全一致，考前适应价值极大
- **写作预测精准**：15年+预测经验，命中率较高
- **AI口语测评**：录音后AI即时评分，反馈发音和流利度
- **社区活跃**：大量考生分享经验和资料
- **免费核心功能**：口语题库和真题预测功能免费

## 用户体验缺点

- **仅限雅思**：只能用于雅思备考，通用性差
- **收费项目多**：虽然核心功能免费，但AI测评、高级课程等收费项目较多
- **界面设计老旧**：UI偏工具化，视觉体验一般
- **AI能力有限**：AI口语测评只是基础评分，缺乏深度反馈
- **广告较多**：免费版有课程广告
- **写作批改需额外付费**：AI/人工批改都要额外购买

## 内容资源特点

- **口语题库**：当季Part 1/2/3全部话题，标注新题/旧题
- **写作题库**：大作文/小作文话题库+预测
- **机考模拟**：1:1还原真实机考界面
- **听力真题**：历年雅思听力真题
- **阅读真题**：历年雅思阅读真题
- **AI口语测评**：口语录音的AI评分
- **写作批改**：人工/AI写作批改服务

## 收费模式

| 类型 | 价格 | 说明 |
|------|------|------|
| 免费版 | 0元 | 口语题库+真题预测+基础功能 |
| AI口语测评 | 按次收费 | AI评分和反馈 |
| 写作批改 | 按篇收费 | 人工/AI批改 |
| 课程购买 | 按课程收费 | 雅思备考系统课程 |
| 会员 | 约20-50元/月 | 解锁全部功能 |

**商业模式**：免费核心功能+付费AI/人工服务+课程销售

## 人工智能结合

- **AI口语测评**：录音评分，评估发音/流利度/词汇
- **AI写作批改**：基础语法和词汇检查
- **AI预测算法**：基于历史数据的考试话题预测
- **AI能力评价**：AI能力中等，口语测评和写作批改基本可用，但反馈深度不如专业教师

| AI测评 | ★★★☆☆ 基础评分但深度有限 |

**典型用户反馈**：
- 正面："雅思口语题库超全，考试真的遇到了原题！机考模拟也很好用"
- 负面："AI口语测评太简单了，就给个分数，不知道哪里说得不好"

## 与其他竞品相比的优势

1. **口语题库最权威**：15年+积累，更新最快最全
2. **机考模拟最真实**：1:1还原真实界面
3. **官方合作伙伴**：雅思官方合作伙伴身份
4. **社区最活跃**：国内最大雅思考生社区
5. **免费核心功能**：题库和预测免费

## 借鉴点

1. **垂直领域深耕**：聚焦一个考试做到极致，成为"必装工具"
2. **当季题库实时更新**：时效性是考试工具的核心竞争力
3. **机考模拟1:1还原**：让用户在真实界面中练习，降低考试焦虑
4. **免费核心+付费增值**：题库免费获客，AI服务付费变现
5. **考生社区**：用户生成内容和经验分享

## 存在问题

1. **仅限雅思**：市场天花板有限
2. **AI能力有限**：评分和反馈深度不足
3. **界面老旧**：工具化设计不够现代化
4. **通用性差**：无法扩展到其他英语学习场景

## 总结

雅思哥是雅思备考领域的绝对王者，通过垂直深耕成为考生"必装工具"。其免费题库+付费AI服务的模式值得借鉴。对Bottle English而言，雅思哥证明了**垂直领域深耕+实时更新的内容**是考试工具的核心竞争力。如果Bottle English未来扩展到考试领域，AI口语测评和写作批改的深度反馈将是关键差异化点——**不只是给分数，更要告诉用户"为什么"和"怎么改"**。
