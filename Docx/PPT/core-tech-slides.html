五级词汇分析流水线 — 将 Krashen i+1 假说工程化

“LLM 只在第四级出场，前三级全部是确定性算法”

架构图 / Five-Level Pipeline

Level 1
词典直查 130KB CEFR 词典常驻内存，O(1) Map 查表，覆盖高频词与标准词形。
纯算法
Level 2
后缀规则还原 9 条后缀规则处理 ies→y、ed→""、ing→"" 等常见词形变化。
纯算法
Level 3
不规则词形 + 缩写还原 20+ 不规则 lemma 与 80+ ASR 非标缩写映射，专门修正常见转写噪声。
纯算法
Level 4
LLM 批量词形还原 仅对未命中词触发批量调用，减少无效请求，显著压缩调用量与 token 成本。
LLM
Level 5
三路分类输出 ≤target 过滤 / =target+1 i+1 保留 / ≥target+2 降级替换，形成 rewrite planning。
分类输出

关键技术要点

  1. 前三级零延迟：词典直查 + 后缀规则 + 缩写还原覆盖 85%+ 词汇，前端 vocabAnalyzer 单例缓存实现实时 CEFR 标注。
  2. 80+ 条 ASR 缩写适配：如 gonna→go、dont→do 等非标输出专项修正，避免转写文本误判等级。
  3. LLM 精准降级：超纲词替换精确对齐目标 CEFR 等级，如 eschew(C1) → avoid(B1)，禁止过度简化。
  4. 批量优化：多句合并批量生成讲解，长课文把原本逐句调用压缩为少量 LLM 请求，形成低成本 i+1 pipeline。

关键技术要点

  1. 静默感知分段：FFmpeg silencedetect 以 -30dB 阈值搜索自然停顿点，降低单词被切断的风险，并支持长音频并行 ASR。
  2. 三道门控：18 种事件驱动状态机，每句设置 3 道门（播放完成 + 听写正确 + 回放确认），全部通过才可进入下一句。
  3. 字符级 5 状态反馈：撇号自动填充、$→口语化 转换、2 字符容错等规则均在前端本地完成，实现亚秒级反馈。
  4. 渐进式辅助：根据重播次数驱动提示从“无提示 → 首字母 → 前两字母 → 完整单词”逐级升级，区分独立回忆与辅助回忆。
